# RFC 7807 problem details

Every response with status >= 400:
- header `content-type: application/problem+json`
- body `{ type: string, title: string, status: number, detail?: string, instance?: string }`
- `status` equals the HTTP status. `type` is a URI (use `about:blank` or `https://errors.example/<slug>`).
- Validation failures may add `errors: Array<{ path: string; message: string }>`.
- Unknown routes → 404 problem; wrong method → 405 problem; uncaught errors → 500 problem without stack traces.
